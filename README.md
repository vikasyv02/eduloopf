# Eduloop (Replaceable with WhatsApp)
A centralized web platform designed to replace cluttered WhatsApp groups, providing a structured and efficient way for communities to manage information, share resources, and coordinate activities.

# 🚀 Key Features
    🔍 Lost & Found: 
    A dedicated space to report lost items or post found objects, reducing the "did anyone see my..." spam in group chats.

    🗃️ Vault: 
    A secure repository for important documents, study materials, or community resources that need to be accessible at all times.

    📢 Announcement: 
    A clear, prioritized feed for important updates, ensuring critical information is never lost in a sea of casual messages.

    📅 Events: 
    A built-in calendar and management system to track upcoming meetups, deadlines, and community gatherings.

# 🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript

Backend/Storage: Node.js, MongoDB Atlas

Deployment: Vercel, Render
